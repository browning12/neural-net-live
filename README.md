# Neural Net live

Live tracker for the day's published Neural Net board: prop spots, leans and straight-up picks, with a Refresh button that pulls ESPN's live box scores in the browser.

This repo only hosts the page. It is rebuilt and pushed each morning from the private Neural Net repo; the logs, data and model live there. Numbers here are unofficial. For entertainment and analysis, not betting advice. 1-800-MY-RESET.

## Phone app

Open the page in Chrome on Android and tap "Add to home screen as an app" (or Chrome menu, Install app). On an iPhone use Safari, Share, Add to Home Screen. The app refreshes itself each morning with the new board and links to the main site and the daily review.
